# Kinetics across all 35 BioModels

**8 November 2026: all 35 baseline computations pass independent comparisons.**
This expands the numerical reference layer beyond the five models in the
selected memory demonstrations. Full-catalog memory protocols and JAX coverage
remain active work.

The [catalog](models/catalog.json) follows supplementary Table S1 of
[Biswas, Clawson and Levin](https://pmc.ncbi.nlm.nih.gov/articles/PMC9820177/).
All 35 original XML files are checked in. The [manifest](models/manifest.json)
records source URLs, names, retrieval dates and SHA-256 hashes. The five
previously downloaded files retain their original hashes and provenance.

## What was computed

Each model runs from its encoded initial conditions over **0 to 50 native model
time units**, sampled at **5,001 times**. Models have different physical time
units; this common numerical window follows our initial memory calibration
window. It does not establish a steady state for every model. Native events
and time-dependent inputs remain active. “Baseline” means that we add no
experimental stimulation to the original encoding.

We observe all species as concentrations, including fixed and assignment-rule
species, plus every additional rule or event target: **380 named observables
across the catalog**. Comparing only reaction species would miss dynamical
rate-rule parameters, including part of the reduced Tyson model's state.

- **34 models:** unchanged SBML is simulated by libRoadRunner/CVODE and
  COPASI/LSODA. Full trajectories agree within the declared mixed tolerance.
- **Scheper1999, network 14 / BIOMD0000000024:** a delay of four native time
  units requires a different route. RoadRunner rejects the delay expression and
  COPASI's native deterministic run fails. A model-specific adapter preserves
  the delay and compares SciPy/DOP853 method of steps with JiTCDDE.
- **36 tests pass** with the optional JAX and delay dependencies installed.
  Analytic checks cover concentration units, rate-rule parameters, assignment
  species, time-dependent expressions, event-induced rate changes and delay
  history. The previous memory tests remain in the suite.

The [complete report](results/catalog/report.json) records rules, events, delays,
compared variables, initial/final values, versions, source-code hashes and
errors. [Individual reports](results/catalog/) are also available. Compressed
trajectories are regenerated by the command below and excluded from git.

Reference solver tolerances are `rtol=1e-10`, `atol=1e-12`. Agreement requires

```text
abs(a-b) <= 1e-7 + 2e-5 * max(abs(a), abs(b))
```

at every sampled time for every observable. The largest normalized discrepancy
is approximately **0.675**, in the Marhl calcium oscillator; values at or below
one pass. Absolute tolerances are in each observable's native units and do not
establish accuracy relative to arbitrarily small concentrations.

## Reproduce the catalog

From `python/`, with Python 3.12 and a C compiler for JiTCDDE:

```sh
uv sync --locked --extra test --extra delay
uv run --locked --extra test --extra delay python -m pytest -q
uv run --locked --extra delay python -m grn_memory.catalog_validation --workers 2
```

Models run in isolated subprocesses with timeouts and separate logs. This also
avoids an observed macOS library conflict: loading SymEngine/JiTCDDE before
RoadRunner in one Python process caused a native crash. The delay-engine test
likewise runs in its own process. A failed worker, missing output, non-finite
trajectory or failed comparison makes the catalog command fail.

Use `--network 14` for one paper network, `--duration` and `--dt` to change the
window, and `--output` to retain a separate experiment. The
[catalog CI job](../.github/workflows/python-replication.yml) installs the delay
extra, runs the analytic checks and regenerates all 35 comparisons on Linux.

Downloading is unnecessary for normal reproduction. To reconstruct the source
collection, this command verifies existing hashes and obtains missing files:

```sh
uv run --locked python -m grn_memory.fetch_catalog
```

## The delayed clock

The [Scheper model](https://pmc.ncbi.nlm.nih.gov/articles/PMC6782369/) has

$$\dot M=\frac{r_M}{1+(P/k)^n}-q_M M,\qquad
\dot P=r_P M(t-\tau)^m-q_P P.$$

The SBML specifies `tau=4`, not zero. Replacing delayed mRNA by its current value
would change the model. Our [adapter](grn_memory/scheper_delay.py) is restricted
to the recorded model hash, reads its parameters and initial amounts, and
declares constant prehistory `M=P=1` for `t<=0`. The common compartment volume
cancels when amount rates become concentration derivatives. `EmptySet` stays zero.

One solver advances in delay-sized intervals using previously solved dense
trajectories as history. The other uses JiTCDDE's independently generated equations
and cubic history representation. Its fixed step is `0.001`; a second run halves
that to `0.0005`. A microscopic first step handles the initial derivative
discontinuity while retaining the initial state and early trajectory. The
maximum independent-solver absolute difference is about **2.34e-9**, and the
step-halving difference is about **7.92e-11**.

An analytic test uses `y'(t)=y(t-1)` with constant prehistory. Its exact piecewise
polynomial checks delayed history, including interval boundaries. This adapter
does not add general SBML delay support to RoadRunner, COPASI or Jaxkineticmodel.

## Remaining work toward the broader goal

The existing concentration-reset runner accepts **22** of the 35 encodings.
Thirteen need additional handling or eligibility decisions for rules, time,
events, delays or mutable parameters. Baseline agreement does not validate
interventions automatically: restarting time at zero can replay an event, and
restoring only concentrations can lose a rate-rule parameter or delay history.

Several saved MATLAB state vectors also differ in length from the current
independent SBML species lists. Some encodings include derived totals or fixed
boundary species. Historical numeric indices require verified symbol identities
before they can define interventions in the new simulations.

The [catalog memory screen](CATALOG_MEMORY.md) now supplies a separate
complete-state intervention route and runs 538 single-input cases across all 35
models. The older concentration-reset runner retains its strict guard; it has
not been made permissive for models whose state it cannot preserve.

The remaining milestones are:

1. Complete catalog-wide paired learning, delayed probes and repeated input
   using the validated state/history-preserving interventions.
2. Extend memory-protocol coverage across the catalog, distinguishing original
   classifications from corrected controls and failures.
3. Establish per-model JAX coverage against these references and resolve the
   unsupported features required by the selected models.
4. Report population-level conclusions after the corresponding experiments
   finish. Random-network comparisons remain a separate expansion.

The [eight selected experiments](RESULTS.md) and their
[three-engine comparison](JAX_VALIDATION.md) remain the completed memory baseline.
This catalog milestone supplies a broader numerical foundation.
